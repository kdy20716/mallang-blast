🗑️ 데이터 삭제 안내

말랑블라스트(com.MallangGames.MallangBlast)의 데이터 삭제 방법을 알려드려요.

시행일자: 2026년 10월 16일

1. 어떤 데이터가 저장되나요?

말랑블라스트는 계정 생성·로그인 없이 이용하며, 게임 진행 데이터(재화, 말랑이 보유 현황, 점수, 설정, 출석 기록)는 이용자의 기기 내부에만 저장됩니다. 개발자의 서버에는 이용자의 개인 데이터가 저장되지 않습니다.

2. 직접 삭제하는 방법 (즉시 삭제)

  • 앱 삭제: 홈 화면의 말랑블라스트 아이콘을 길게 눌러 ‘삭제/제거’ → 기기 내 게임 데이터가 함께 삭제됩니다.
  • 앱 데이터만 삭제: 설정 → 앱 → 말랑블라스트 → 저장공간 → ‘데이터 삭제(저장공간 비우기)’
  • 웹 버전 데이터 삭제: 브라우저 설정 → 사이트 설정(또는 개인정보 보호) → 이 사이트의 저장된 데이터 삭제

3. 광고 식별자(광고 ID) 관련 데이터

광고 제공을 위해 Google AdMob이 광고 ID 등을 처리할 수 있습니다. 이 정보는 Google이 관리하므로 아래 방법으로 직접 제어할 수 있어요.

  • Android 설정 → 개인정보 보호(또는 Google) → 광고 → ‘광고 ID 삭제’ 또는 ‘재설정’
  • Google 내 광고 센터에서 맞춤 광고 설정 변경

5. 삭제 후 유의사항

삭제된 게임 데이터(재화, 말랑이 등)는 복구할 수 없습니다. 자세한 내용은 개인정보처리방침과 이용약관을 참고해 주세요.
